# Stayplaytion GameFront

**Статус:** игровая оболочка находится в активной разработке в ветке Stage 4.x. Сборки и CI не заменяют аппаратную проверку каждого контроллера и каждого эмулятора.

Исходники: [ports/frontend в development branch](https://github.com/irman100/H3531/tree/feature/h3531-stage68-desktop-input-polish/ports/frontend).

## Назначение

GameFront — отдельный игровой frontend поверх Stayplaytion Desktop. Он предназначен для просмотра библиотеки систем и игр и запуска зарегистрированных приложений/эмуляторов. Он не заменяет постоянный LXDE Desktop, FILES или Native App Bridge.

## Реализованные направления

- библиотека систем и игровых записей;
- медиакарточки и оформление систем;
- поиск и избранное;
- главное меню, настройки и горячие клавиши;
- мастер настройки контроллера;
- захват и калибровка аналоговых осей;
- обработка стандартных и fallback input events;
- адаптивная обработка осей и настройки для разных геймпадов;
- более спокойный запуск приложений без лишних повторных событий.

Ветка содержит последовательные этапы Stage 4.30–4.48. Это история итеративной разработки интерфейса и input stack, а не утверждение, что все найденные устройства уже имеют готовый профиль.

## Аппаратная проверка

Перед объявлением GameFront готовым нужно отдельно проверить навигацию с клавиатуры и геймпада, работу мастера настройки, dead-zone/axis capture, повтор горячих клавиш и запуск/возврат каждого зарегистрированного приложения на Hi3531.
