# Как опубликовать GitHub Release для H3531 Home Computer

Эта инструкция относится к публичному демо `v0.7-fbzx-z80-demo`.

## 1. Открыть страницу Releases

На главной странице репозитория `irman100/H3531` справа найдите блок **Releases** и нажмите **Create a new release**. Если вы уже на странице Releases, нажмите **Draft a new release**.

## 2. Создать тег

В поле **Choose a tag** введите:

```text
v0.7-fbzx-z80-demo
```

Выберите **Create new tag** и в качестве Target оставьте ветку:

```text
main
```

Release в GitHub привязывается к Git tag, то есть фиксирует конкретное состояние проекта.

## 3. Название Release

В поле **Release title** укажите:

```text
H3531 Home Computer v0.7 — Public Z80 Demo
```

## 4. Описание

В поле **Describe this release** можно вставить текст из:

```text
docs/releases/v0.7-fbzx-z80-demo.md
```

Основная идея релиза: безопасный USB/RAM запуск H3531 Home Computer и физически проверенный запуск `.Z80` из FILES через FBZX.

## 5. Прикрепить готовый ZIP

Ниже описания находится область для бинарных файлов. Перетащите туда:

```text
H3531-Home-Computer-USB-Kit-v0.7-fbzx-z80.zip
```

Либо нажмите ссылку выбора файлов в этой области и укажите ZIP на компьютере.

Не распаковывайте ZIP перед загрузкой: он должен быть одним Release Asset.

## 6. Отметить как предварительный релиз

Так как это экспериментальная публичная сборка, включите:

```text
This is a pre-release
```

Это правильно отражает текущее состояние проекта.

## 7. Проверить перед публикацией

Перед нажатием Publish убедитесь, что:

- выбран тег `v0.7-fbzx-z80-demo`;
- Target = `main`;
- название заполнено;
- описание вставлено;
- ZIP полностью загрузился и виден среди assets;
- включен флаг **This is a pre-release**.

## 8. Опубликовать

Нажмите:

```text
Publish release
```

После публикации на главной странице репозитория справа в блоке Releases появится `v0.7-fbzx-z80-demo`, а посетители смогут открыть релиз и скачать ZIP из раздела **Assets**.

GitHub также автоматически добавляет `Source code (zip)` и `Source code (tar.gz)`. Это архив исходников репозитория, а не наш готовый USB Kit. Пользователю для запуска нужен именно вручную прикрепленный файл `H3531-Home-Computer-USB-Kit-v0.7-fbzx-z80.zip`.

## Важно о ROM и играх

ZX Spectrum ROM-файлы и игры не входят в USB Kit и не публикуются в репозитории. Пользователь должен добавить собственные законно полученные `48.rom`, `if1-2.rom` и `.z80` snapshot-файлы самостоятельно.
