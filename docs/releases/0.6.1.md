# H3531 Home Computer 0.6.1

Milestone: **Game Cleanup & Widescreen**.

## Fixes

- Matrix Brandy `H3531-PADDLE.BAS` now uses widescreen `MODE 71` (1024x576 graphics / 16:9) instead of `MODE 27` (640x480 / 4:3).
- BASIC graphics startup/exit uses `CLG:CLS` so both graphics and text layers are cleared.
- Fixed the paddle erase bug: the old paddle is erased with `RECTANGLE FILL`, not only a rectangle outline.
- Simplified the BASIC refresh loop so drawing is accumulated under `REFRESH OFF` and shown with one-shot `REFRESH`.
- Native SDL Pong now requests a 640x360 16:9 logical surface. On the H3531 1280x720 framebuffer this scales exactly 2x, removing letterbox bars and fractional dirty-rectangle scaling.

## Verification

- Native SDL Pong cross-build: GitHub Actions success.
- RAMDisk 0.6.1: U-Boot header CRC, U-Boot payload CRC and CramFS CRC verified offline.
- Physical validation of the corrected games is still required.

## Expected visual result

Both games should now use the full 16:9 display. The BASIC paddle must move without leaving cyan copies behind, and exiting/restarting a game should continue to use the exclusive graphics session model from 0.5.3/0.5.4.
