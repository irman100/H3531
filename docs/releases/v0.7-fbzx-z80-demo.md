# H3531 Home Computer USB Kit v0.7-fbzx-z80-demo

> **Архивная запись.** Это описание относится только к первоначальному USB Kit v0.7. Старый Git tag `v0.7-fbzx-z80-demo` и прежний ZIP больше не доступны. Текущий публичный файл размещён в [релизе StayPlaytion](https://github.com/irman100/H3531/releases/tag/StayPlaytion): [`SP.rar`](https://github.com/irman100/H3531/releases/download/StayPlaytion/SP.rar) (RAR, 179 238 987 байт). Не используйте старую инструкцию ниже как описание содержимого нового архива.

Первый публичный минимальный набор для повторения эксперимента H3531 Home Computer на Hi3531/AHB70XXT16-3531 DVR-платформе.

## Что входит

- безопасный USB/RAM boot kit layout;
- `H3531.IMG` с Monitor и FILES;
- `zImage.img`;
- `h3531-video-init` и `h3531-input-init`;
- `FBZX.APP` для запуска `.Z80` snapshot-файлов из FILES;
- `keymap.bmp`;
- README и SHA256SUMS.

## Что проверено

- собственный HDMI framebuffer output;
- USB-клавиатура и USB-накопитель;
- H3531 Monitor / FILES;
- BASIC-среда;
- запуск `.Z80` через FBZX из файлового менеджера;
- возврат в Monitor после выхода приложения.

## Чего нет в архиве

ZX Spectrum ROM и игры не включены. Их нужно добавить самостоятельно:

```text
spectrum-roms/48.rom
spectrum-roms/if1-2.rom
Games/*.z80
```

## Безопасность

Не используйте `saveenv`. Не прошивайте экспериментальные образы в SPI Flash. Этот выпуск рассчитан на загрузку из USB/RAM.
