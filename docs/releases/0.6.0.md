# H3531 Home Computer 0.6.0

Milestone: **Games & Native SDL Apps**.

## Added

- `examples/basic/H3531-PADDLE.BAS` — original interactive Matrix Brandy graphics game. Arrow keys or A/D move the paddle; Q exits.
- `apps/native/h3531-sdl-pong.c` — original native ARM Linux SDL 1.2 Pong application. Arrow keys/A-D or mouse control the player paddle; Esc/Q exits.
- `.github/workflows/h3531-apps-build.yml` — reproducible ARMv7 EABI5 soft-float static cross-build for native SDL applications using the project H3531 SDL backend.
- Monitor 0.6.0 commands planned in the firmware bundle: `GAMES`, `PADDLE`, `PONG`; F9 launches the BASIC game and F10 launches native SDL Pong.

## Architecture checkpoint

Both the BASIC game and the native Linux application use the same graphics/input layer:

```text
Matrix Brandy BASIC -> SDL 1.2 H3531 -> fb0/evdev -> HIFB -> HDMI
Native Linux C      -> SDL 1.2 H3531 -> fb0/evdev -> HIFB -> HDMI
```

Graphical applications continue to use the exec-session ownership model introduced in 0.5.3. FILES resume state from 0.5.4 is retained.
